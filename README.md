# 夜航练习室

## 本地启动

```sh
npm ci
npm run dev
```

在浏览器打开 Vite 输出的本机地址。麦克风需要本机地址或 HTTPS。

## Docker 启动

```sh
docker compose up --build
```

打开 <http://localhost:8029>。可以通过 `NIGHT_SESSION_PORT` 指定其他端口。

## 延迟校准

录音前在左栏「延迟校准」发起一次测试：应用播放多脉冲测试音并用麦克风回录，
分析器以归一化互相关在回录里寻找每次脉冲的全部抵达（多峰），输出候选偏移与判定依据。

- **弱直达 / 强反射**：自动选择最早的稳定抵达作为第一声，并在说明里标注其后的反射峰。
- **两次抵达无法区分（< 25ms）或重复性不足**：判定为歧义，保留上次确认值并要求人工重新判定，
  可在波形图上点击标出实际听到的第一声，或点候选行反复试听。
- **输出路径无法识别**：浏览器无法对应具体扬声器时显示「未知输出」，必须人工确认输出设备后才能保存。
- 校准值绑定输入设备、输出设备与采样率；设备切走再切回原组合时自动恢复，组合变更则提示重新校准。
- 每条录音保存当时的校准解释：旧录音按零偏移解释并标注「旧录音 · 未校准」，
  新录音显示校准状态；试听游标与音高曲线共用同一偏移。
- 历史校准保留原始测试音与回录，可随时「重新验证」。

## 测试

```sh
npm test        # 纯逻辑测试：多峰回声、近距双峰歧义、线路中断、设备切回恢复、偏移一致性

```
